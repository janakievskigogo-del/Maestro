# Maestro . SmartResto POS
Модерна, целосна веб-апликација за управување со нарачки во ресторани, дизајнирана за келнери (мобилен телефон), кујнски персонал и бар (таблети/KDS), како и администрација на ресторани.
Работи на чист Python (без надворешни пакети) со SQLite база на податоци.
---
##  Клучни карактеристики
### 1. Брз преглед на нарачката (Compact Order Summary Bar)
- **Леплив/пловечки бар** на дното на екранот за нарачки за келнери.
- Прикажува кондензиран приказ на сите одбрани ставки во еден ред (на пр. `2x Margherita, 1x Coca-Cola, 1x Schweppes - Вкупно: 790 ден.`).
- Келнерот може веднаш да ја прочита целата нарачка назад на гостите на масата со еден поглед, без да скрола низ долги картички.
- Целосната детална кошничка со состојки, алергии и забелешки останува достапна веднаш до брзиот преглед.
### 2. Mobile-First UI/UX & PWA можности
- **Мобилен приказ за келнери**: Долна лента за навигација (Bottom Navigation Bar) со лесни за притискање големи копчиња (Маси, Готови ставки со бројач).
- **Progressive Web App (PWA)**:
  - Вклучен `manifest.json` и векторски икони за "Add to Home Screen" на iOS и Android.
  - Service Worker (`sw.js`) со стратегија **Cache-First за статички ресурси** и **Network-First за API**.
  - Автоматски **офлајн индикатор** кога нема интернет врска.
### 3. Мулти-ресторанска архитектура (Multi-Restaurant)
- Сите податоци (маси, категории, мени, состојки, нарачки) се изолирани и врзани за `restaurant_id`.
- Секој вработен при најава автоматски го вчитува профилот, менито и масите за својот ресторан без потреба од посебни веб-страници.
- **Супер-администратор (`super_admin`)**: Единствена контролна табла за креирање нови ресторани, поставување валута (MKD, EUR, USD) и доделување на почетни менаџери.
- Строга изолација: Персоналот од еден ресторан не може да гледа ниту менува нарачки од друг ресторан.
### 4. Kitchen Display System (KDS) и Звучни/Вибрациски известувања
- **KDS Темна тема**: Екраните за кујна и бар автоматски се префрлаат во темна тема со висок контраст, идеална за ѕидни или кујнски таблети.
- **Синхронизација во живо**: Автоматско освежување во позадина.
- **Инстантни аларми за келнерот**: Кога ставка е означена како "Готово" од кујната или барот:
  -  Јасен двотонски звучен сигнал преку Web Audio API (работи офлајн без надворешни аудио датотеки).
  -  Вибрација на телефонот на келнерот (`navigator.vibrate`).
  -  Browser Web Notification (известување на заклучен екран / статус бар).

##  Стартување
Потребен е Python 3.11 или понов.
```powershell
python server.py
```
Отворете: **[http://127.0.0.1:8000](http://127.0.0.1:8000)**
За пристап од други уреди (телефони/таблети) во иста локална Wi-Fi мрежа:
```powershell
$env:HOST = "0.0.0.0"
python server.py
```

##  Демо-корисници (Лозинка: `demo123`)
| Корисничко име | Улога | Опис |
| --- | --- | --- |
| `waiter` | Келнер | Преглед на маси, отворање нарачки, брз преглед, звучни известувања за готови јадења |
| `kitchen` | Кујна (KDS) | Темна KDS табла, преглед на нарачки за кујна, означување подготвеност и алергии |
| `bar` | Бар | KDS табла за пијалаци, започнување и завршување на пијалаци |
| `admin` | Администратор | Управување со мени, цени, состојки, маси и персонал на ресторанот |
| `superadmin` | Супер-администратор | Креирање нови ресторани (multi-tenant), преглед на статистика и доделување админи |
